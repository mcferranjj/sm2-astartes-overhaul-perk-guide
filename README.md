# SM2 Modded Perk Guide

A static page listing the class and weapon perks as the Warhammer 40,000: Space Marine 2
"Astartes Lite" mod has them, for players whose in-game menus still show vanilla numbers.

Everything is in `index.html`. There is no build step and no dependencies.

## Notes

- Perk names and numbers come from the mod's own UI files and string table, so a value the mod
  changed without updating its UI text can lag behind the real number.
- Perks the mod adds or reworks without any in-game text are shown by a name derived from their
  internal ID and are flagged on the page.
